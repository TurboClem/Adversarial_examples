## Setup Instructions

Run these scripts in order :

```bash
# 1. Download data (to workspace)
bash sh_scripts/download_data.sh

# 2. Save to persistent storage
bash sh_scripts/save_data.sh

# 3. Create symlink (if data disappears)
bash sh_scripts/retrieve_data.sh
```

**Note:** Run from your project root folder.
